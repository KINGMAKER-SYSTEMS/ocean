Fixed the encoded-URI classification edge (factory FQ-K9, Codex P2 review comment 4339757530 on #143, left unaddressed when the content landed via #147): `preserve_database_uri` in `apps/ocean-surface/crates/ocean-tauri/src/lib.rs` judged `OCEAN_DB_PATH`/`OCEAN_TITLES_DB_PATH` `file:` URI absoluteness on the raw encoded path slice, so a valid percent-encoded absolute URI such as `file:%2Ftmp%2Frooms.db` — which SQLite's URI parser percent-decodes to `/tmp/rooms.db` before opening (confirmed with the sqlite3 CLI: `PRAGMA database_list` reports the decoded absolute file, and `file:%3Amemory%3A` reports an in-memory database with no stray file) — failed before daemon spawn with "requires an absolute file URI or an in-memory database URI".
