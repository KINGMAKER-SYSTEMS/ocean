Re-did the portable parts of Risingtides-dev/ocean-surface#230 fresh against the monorepo's single-daemon proxy (`apps/ocean-surface/crates/ocean-surface-proxy/src/main.rs`). (1) Upstream path normalisation: hyper accepts a raw backslash in the request target, `has_dot_segment` split on `/` only, and every forwarder formatted a String URL that reqwest's WHATWG parser rewrote (`\` to `/`, dot segments collapsed), so `GET /v1/rooms/persistent/team\..\..\..\agent\sessions` reached `/v1/agent/sessions` and the owner-mutation shapes could carry the operator key to a route the table never exposed. Now `has_dot_segment` also refuses raw and encoded backslashes (400 `invalid path`), new `upstream_url(daemon_url, path, query)` parses the outgoing URL and refuses it unless the parsed path equals the approved path (400 `upstream_path_rewritten`), every forwarder sends the checked `reqwest::Url` (turns, sessions, session detail, the JSON helpers including the operator-key one, fs dirs/file, history search, GitHub templates, projects, component event, calls, realtime secret, session messages/steer, LiveKit token, requests, cancel, browser screencast/input, longhouse, rooms-persistent including the SSE tail, control/agent events, observatory, stt, tts), captured `{id}` segments are rebuilt as one segment via `daemon_path_with_segment`, longhouse forwards its raw path instead of the decoded capture, and `rebuild_from_template` uses the same guard. (2) Auth-off CSRF gate: the proxy had no Origin/Referer policy at all; `auth_off_cross_site_gate` (inside the session gate) now refuses every non-GET/HEAD request under `/v1/` and `/api/` with 403 `cross_site_mutation_refused` unless every supplied Origin/Referer names the exact loopback Host; headerless clients still pass; auth-on relies on the SameSite=Strict cookie (pinned by a test). Not ported: the session-actor binding and room-owner gate (a multi-device roster model the monorepo lacks), the JSON content-type lane, and the every-request loopback-Host refusal. Tests in new `src/tests/path_csrf.rs` (12): unit tests for both halves and the source policy, backslash probes across every family over oneshot and real TCP against a recording upstream (operator key proven on the control, empty log on the probes), exact-path passthrough including monorepo shapes (`/steer`, `/v1/rooms/inbox`, GitHub captures, `project%3Asurface-main`), captured dot segments on every id family, CSRF refusal/admission across 27 mutating routes; a mutation run with both halves disabled makes the TCP probe test fail with the normalised path in the upstream log. Contract in `apps/ocean-surface/AGENTS.md`. Validation from the proxy crate with a private target dir: `cargo build --locked`, `cargo test --locked` 50 passed (38 existing + 12 new), `cargo clippy --all-targets -- -D warnings` clean, `cargo fmt --check` clean. No shared UI code moved, so `cargo test -p ocean-surface-ui` was not needed.
