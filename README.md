# Ocean

Private unified workspace for the KINGMAKER-SYSTEMS team.

This repository brings Ocean's canonical codebases into one history-preserving
workspace while retaining each project's ownership, build, licensing, and
security boundaries.

## Layout

- `platform/ocean-os` — Rust runtime, daemon, TUI, tools, and execution authority
- `apps/ocean-surface` — shared web, native, editor, voice, and canvas clients
- `packages/ocean-agents` — reusable profiles, packages, and transport conventions
- `services/ocean-bedrock` — private shared knowledge and data services
- `org/risingtides-agents` — private production assistants, SOPs, and workflows

See `AGENTS.md` for routing and contribution rules.
